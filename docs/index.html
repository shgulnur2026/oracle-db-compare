Сравнение таблиц территориальных БД Oracle с республиканской

Локальное веб-приложение на Python: проверяет, что записи территориальных БД есть в республиканской и что у них заполнено поле BlobArch; проблемные записи выгружает в файл, таблицы ANL и дамп Data Pump.

Приложению нужен доступ к вашим базам Oracle, поэтому оно запускается только на вашем компьютере. Эта страница — описание.

Запуск

pip install -r requirements.txt
python app.py

Откройте http://127.0.0.1:8765.

Возможности

  • Этап 1: сравнение по ключам ID+KNR, порциями по 500, результат в compare_result_<район>.txt.
  • Этап 2: таблицы <ТАБЛИЦА>ANL и экспорт через DBMS_DATAPUMP.
  • Режим «множество БД» из Excel/CSV, параллельная обработка до 32 потоков, файл сводки.
  • Пароли не сохраняются и не пишутся в лог.
