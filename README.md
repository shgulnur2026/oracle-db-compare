# Сравнение таблиц территориальных БД Oracle с республиканской

Реализация по [prd.md](prd.md).

```
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:8765 (сервер слушает только локальный адрес).

- Этап 1: `compare_result_<район>.txt` (`REGION|TABLE|ID|KNR|REASON`) и `compare_log_<район>.log`.
- Этап 2: таблицы `<ТАБЛИЦА>ANL` и дамп Data Pump `compare_anl_<район_латиницей>.dmp` на сервере БД;
  лог `compare_log_anl_<район>.log`. Параметры (папка, имя результата, таблицы, район) должны совпадать с этапом 1.
- Режим «множество БД»: Excel/CSV, шаблон — ссылка на странице; сводка `compare_summary[_anl].txt`.
- Пароли не сохраняются и не логируются; остальные поля запоминаются браузером.
